# Olive Video Editor [![Build status](https://github.com/olive-editor/olive/workflows/CI/badge.svg?branch=master)](https://www.swifttechco.com)

## Images

[![olive](https://opengraph.githubassets.com/1/olive-editor/olive)](https://www.swifttechco.com)


Olive is a free non-linear video editor for Windows, macOS, and Linux.

[![screen](https://olivevideoeditor.org/img/020-2.png)](https://www.swifttechco.com)


**NOTE: Olive is alpha software and is considered highly unstable. While we highly appreciate users testing and providing usage information, please use at your own risk.**
